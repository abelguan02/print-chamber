# Print Chamber

将 2D 原画转换为 3D 风格的悬停图片预览。支持本地 FLUX.2 Klein 4B、本机 Codex 登录和自选云端图片接口。

预览以打印机浮层呈现，可钉入出纸托盘、查看打印记录、放大、复制、下载及批量管理。输出是图片，不能旋转或编辑为 3D 模型。

## 使用

1. 在装有 Google Chrome 的 Apple Silicon Mac（macOS 14 或更高版本）上，从 [GitHub Releases](https://github.com/abelguan02/print-chamber/releases) 下载 arm64 安装包。打开 dmg，将 Print Chamber 拖到「应用程序」，推出磁盘映像后从「应用程序」打开。如果 macOS 首次拦截，到「系统设置 → 隐私与安全性」点「仍要打开」。
2. 在 App 设置中点「在访达中显示」和「打开扩展页」。在 Chrome 开启「开发者模式」，点「加载已解压的扩展程序」，选中刚才显示的 `extension` 文件夹。App 显示「已连接」后，在扩展「生成设置」选择生成方式。
3. 云端 API 使用你自己的密钥，本机 Codex 复用已登录的本机账号。本地模型可选用，在 App 设置中下载约 16 GB 的模型后，从菜单栏点「启动模型」。
4. 打开作品页，悬停约 1.2 秒或按住 Alt 悬停即可预览。已有打印记录会直接显示。本地模型自动打印新图；Codex 和云端 API 在你点「打印」后才上传生成。
5. 点「重打」会按当前配置重新生成。本地模型使用新的随机种子，失败时保留上一张结果。

云端 API Key 仅保存在当前浏览器，不会同步，卸载扩展即清除。MiniMax 大陆和海外平台分别保存密钥。使用阿里云百炼时，工作空间、地区和 API Key 必须匹配。

首次在设置页保存云端配置、测试云端连接或试生成时，需要确认上传与计费。删除最后一把供应商密钥后，下次使用需要重新确认。测试连接不会生成图片，试生成及作品页上的“打印”“重打”可能产生费用。供应商接口依据见 [CLOUD.md](CLOUD.md#官方接口依据2026-10-16-核对)。

历史结果在模型停止或切换生成配置后仍可查看，标记为“历史打印”。如果原图在同一地址被替换，或希望使用新模型生成，请点击“重打”。记录仍按现有 48 张及约 7 MB 限制保存，删除或被淘汰后不再复用。升级后请重新加载扩展、刷新作品页，并通过小助手停止后重新启动本地模型，使新种子逻辑生效。

## Mac 上连接本机 Codex

使用 Chrome，并先用 ChatGPT 账号登录本机官方 Codex 独立版或桌面版。

在已配对的扩展中打开「生成设置」，选择「本机 Codex」，点「连接 Codex」并确认额度使用。出现「已连接」后即可到作品页打印。

## 当前验证范围

- 默认提示词为用户确认采用的 G3，保存在 `benchmark_local.py` 与 `extension/cloud-prompt.js`；秋色森林配色漂移仍是已知限制。
- 模拟网站、合成图片下的悬停、打印、托盘、记录与批量操作已有回归测试。图库窄屏布局已覆盖 320–1440 px，打印机保持原比例。
- 真实 ArtStation 作品页、其他真实网站及云端接口效果尚未完成验收。MiniMax 对原画构图、姿势、服饰和背景的保留效果尚未验证。
- 本地推理实验的单图耗时约 2–3 秒，不等于实际悬停端到端耗时。

## 文件范围

| 目录或文件 | 用途 |
| --- | --- |
| `extension/` | 浏览器扩展及本地字体 |
| `service.py`、`benchmark_local.py` | 本地服务与推理基准 |
| `runtime_config.py`、`configure-local.py`、`start-local.command` | 本机路径配置与启动入口 |
| `menu-helper/` | macOS 菜单栏助手源码 |
| `design-reference/`、`build-design.cjs` | 已采用设计来源与编译工具 |
| `extension/icons/`、`build-icons.cjs` | 扩展与小助手共用的统一图标及生成工具 |
| `tests/`、根目录测试脚本 | 自动回归与验证工具 |
| `baselines/`、`BASELINE.txt` | 当前基线说明与不可覆盖的历史归档 |
| `specs/` | 开发任务单与进度 |
| `docs/decisions.md` | 关键决定记录 |
| `docs/archive/` | 过期的说明与验收记录，仅供追溯 |
| `work/` | 审查记录与独立实验脚本 |

仓库不包含模型权重、本机 Python/Node 依赖、`.local/` 连接码和配置、日志、生成的 App、`output/` 图片与对照页，以及已排除的其他聊天实验。部分历史记录引用这些仅在原机器保留的文件；克隆仓库后不会自动拥有对应素材和实验产物。

项目协作与基线边界见 [AGENTS.md](AGENTS.md)。保留的历史归档不等同于当前版本已发布或全部能力已验收。
