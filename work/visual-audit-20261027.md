## 需要修正的布局问题

### P2：图库的打印机在窄窗口撑出内容区

- 320 px 视口下，页面 scrollWidth 为 364 px，横向溢出 44 px；360 px 下为 364 px，溢出 4 px。
- 375 px 下页面 scrollWidth 为 375 px，无页面横向溢出，但打印机的 340 px 容器从 x=24 延伸至 x=364，侵入右侧预期 24 px 留白，仅余 11 px。
- 原因：`extension/gallery.html:21` 的打印机包装层固定为 `flex: 0 0 340px`，`.panel` 也保持 340 px 基础宽度；外层左右各 24 px 留白。`extension/pages.css:9` 的窄屏规则只调整标题、间距及卡片网格，没有适配打印机宽度。
- 对照：悬停打印机由 content.js 按视口计算缩放，320 px 下实测 x=12、宽 272 px，显示正常。图库需要自己的窄屏缩放或容器适配，不能只隐藏横向滚动。
- 证据：[320 px 图库](../output/visual-audit-20261027/gallery-320.png)、[360 px 图库](../output/visual-audit-20261027/gallery-360.png)、[375 px 图库](../output/visual-audit-20261027/gallery-375.png)、[320 px 悬停](../output/visual-audit-20261027/hover-ready-320.png)。

## 风格一致性：有差异，需按设计决策处理

### 设置页与核心拟物界面采用不同组件体系

`extension/settings.css:1` 采用平面白卡、系统字体、常规表单与深色主按钮；控制面板、打印机和图库沿用原设计的暖色渐变机壳、Doto 状态屏及 IBM Plex Mono 标识。整体色温接近，但表单、按钮材质和品牌字样没有完全统一。

设置页没有对应的原稿板，属于后续新增功能页面；此项是跨页面一致性问题，不据此认定为违反一张已有设置页设计稿。不能为了统一而删除现有连接、费用和配置提示。

### 关于页使用独立视觉语言

`extension/about.css` 使用独立的小打印机、金属边框、粗体渐变大标题和滚动文字；核心界面采用 PC-1 拟物设备及点阵屏。关于页与设置页共享大部分暖灰色值，但关于页的设备造型、标题及圆角层级与核心界面不同。

关于页已有独立 About Kit 来源说明，并保留此前要求的入口和状态；未找到它与最初五块设计板逐项对应的依据，因此列为设计统一事项，不擅自重做。

### 本地试用画廊仍采用早期平面风格

`demo.html:2` 使用独立背景、系统字体、细线与图片瀑布流；没有与图库共用品牌头部、拟物按钮或点阵状态组件。桌面与 320 px 下均未发现横向溢出，但视觉并非同一套完整组件体系。

上述差异属于页面间的材质、排版与品牌呈现差异，不能简单通过统一一个背景色解决。原设计本身就是用户明确指定的暖色拟物风格，本轮没有按全局默认黑白灰偏好重新配色；绿色仅用于原稿既有的状态屏、指示灯和打印标记。

## 方法与验证范围

- 使用隔离临时资料、headless Chromium，未占用用户前台；未修改产品实现、配置、提示词或基线。
- 本轮 `node test-design.cjs` 通过；`node --test tests/about-browser.cjs tests/local-settings-browser.cjs` 的 2 项测试通过。
- 新审查脚本覆盖主要页面及 320 / 360 / 375 / 390 / 768 / 1440 px 中适用尺寸，共新增 38 张审查截图；另复用现有测试本轮重新生成的状态截图。
- 主要页面测量中的 JavaScript 页面错误为 0、可见损坏图片为 0；这些不是对全部运行环境和外部网站的保证。
- 所有生成、健康状态和原画均为模拟或合成测试数据，没有加载模型或调用付费 API。
- macOS 菜单栏助手使用 NSStatusItem / NSMenu 等原生控件，只做源码范围确认。实际原生菜单、深浅系统主题及权限弹窗未截图，不声称视觉验收通过。
- 真实 ArtStation 作品页、Behance、Pinterest 的宿主 CSS、实际浏览器弹窗容器、不同系统字体环境以及真实模型输出仍未验证。
- 审查脚本和截图索引是本轮检查产物；原有未提交工作及历史归档保持原状态。本轮未运行设计构建，避免覆盖当前已有改动。

建议优先修正图库窄屏容器；设置、关于与试用画廊的统一应先确定要沿用核心拟物体系到何种程度，再集中处理。本轮仅检查并记录，未执行视觉修复。
