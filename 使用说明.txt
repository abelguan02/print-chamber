Print Chamber 本地插件

首次使用
1. 双击本目录的 start-local.command。模型加载后，终端会显示“模型已就绪”。保持服务终端打开。
   目前这台电脑的模型与 Python 环境已配置，无需下载模型或填写云 API 密钥。
   如果服务已在运行，此命令只显示连接码，不会重复加载模型。
2. 在 Chrome 打开 chrome://extensions，开启右上角“开发者模式”。
3. 选择“加载已解压的扩展程序”，选择这个目录：
   /Users/abelguan/Desktop/2Dto3DStyle/extension
4. 点击浏览器工具栏中的 Print Chamber，复制本地服务终端里的“插件连接码”，粘贴后点“连接”。
5. 点击插件中的“打开本地试用画廊”，或访问 http://127.0.0.1:8877/demo。
   将鼠标停在原画上，300 毫秒后打开打印舱并开始生成。

交互
鼠标从原图移动到弹窗时保持显示。离开两者 650 毫秒后关闭。
点击右上角固定按钮可持续查看。取消固定后恢复悬停逻辑。
点击关闭或按 Escape 收起。遇到错误可点“重试”。
结果返回后从下向上显现，约 0.42 秒；系统开启减少动态效果时直接显示。
插件开关可以暂停悬停预览。可聚焦的图片链接也支持键盘焦点触发。
右下角显示从悬停触发到显现完成的前端耗时；缓存结果标为“已生成的预览”。

支持范围
当前自动注入 ArtStation、Behance、Pinterest 的 .com/.net 对应域名和本地画廊。
支持正常加载的 img 元素及图片链接内的 img；不覆盖 CSS 背景图、Canvas、跨域 iframe 或所有地区域名。
外部网站可能禁止读取原图；遇到这种情况显示错误，不会绕过网站的访问限制。
扩展申请 HTTPS 图片读取权限，是为了读取站点使用的独立图片 CDN；只在上述站点注入悬停界面。

运行方式
生成完全在本机进行。服务只监听 127.0.0.1:8877，生成请求需要本地连接码。
生成服务不接受远程 URL、不上传图片、没有云服务回退。
沿用 benchmark_local.py 中旧版通用提示词，4 步、固定种子 42，输出约 0.33MP，最长边约 768。
第 3 张先前获认可的角色专用提示词不是插件默认提示词。面罩、表情和亮度偏差仍属于模型已知限制。
模型保持加载，文本提示词预编码。服务器最多保存 24 张内存缓存；图片不自动写入磁盘。
多个标签页共用一个本地 GPU 服务。忙碌时提示稍后重试，不积累长队列。
离开后若生成已经提交，当前计算可能仍会完成，但不会把旧结果显示到新图片弹窗。

停止与配置
在模型服务终端按 Ctrl+C 可停止服务并释放模型。
若服务由开发测试启动，可在终端执行 lsof -ti TCP:8877 -sTCP:LISTEN 查看进程，再确认后停止对应进程。
本地连接码保存在 .local/token，仅用于这台电脑；无需在聊天中发送。
可用 FLUX_MODEL_PATH 指定其他本地模型目录，用 FLUX_PYTHON 指定已有的兼容 Python。
修改插件文件后，在 chrome://extensions 点击插件刷新，再刷新目标网页。

当前交付是可本地加载的开发版，不是商店发布版。
已在隔离测试浏览器与本地画廊验证，真实网站的登录态、CDN 防盗链、悬浮遮罩等仍需逐站验证。
